# DawnMesh 1.0.4（versionCode 42）

- 修复公网房主被显示为「房主已关闭你的麦克风」：区分房间闭麦策略与 LiveKit 媒体发布权限。媒体权限尚未就绪时显示「正在恢复发言权限」，不会把连接同步问题当成房主封麦。
- 媒体连接及管理连接恢复后，重新读取 SDK 权限并同步服务端策略；两者不一致时每十秒自动重试，权限到达后停止重试。自动通话恢复原模式，按住对讲仍需重新按下；真实闭麦不会被绕过。
- 接任房主后不再继承成员时期的闭麦状态；配套服务端 0.2.6 处理主动移交、自动接任和旧数据库中的房主闭麦状态，并避免重试时应用过期权限。
- 强力麦克风降噪增加持续窄频尖啸抑制，Wi-Fi、蓝牙和公网房共用。检测约 0.9–6 kHz 中持续至少约 200 ms、明显占主导的尖声，再平滑加入窄带滤波。短暂瞬态、宽频声音及普通人声谐波不直接触发；标准档保持不变，不增加音频缓冲时长。

此次针对「对方打开头盔镜片后出现、关闭后消失」的情况优化。抑制发生在发出噪声一方的麦克风链路。合成尖啸与风噪测试有效，干净合成语音在新增环节中未被改变；与连续人声重叠、没有明显窄频峰值的噪声会保守处理，因此不能保证所有头盔风噪完全消失。未进行实际头盔开镜片或道路实测。

验证：233 项 Flutter 回归，Android 单元测试与 Lint，Native ASan/UBSan 及 16/32/48 kHz 降噪测试，服务端 Go 竞态测试与 vet，网页构建/类型检查、4 项单测和 16 项浏览器回归。发布包签名及 16 KB 对齐校验通过。

建议配套升级 DawnMesh Server 0.2.6。公网协议仍为 2，无需因本次升级重新创建 0.2.5 的房间。按要求只推送分支与标签，不追踪 GitHub Actions。

平台依据：[LiveKit 令牌与权限](https://docs.livekit.io/frontends/reference/tokens-grants/)、[参与者权限更新](https://docs.livekit.io/intro/basics/rooms-participants-tracks/participants/)；基础降噪模型为 [RNNoise](https://github.com/xiph/rnnoise)。
