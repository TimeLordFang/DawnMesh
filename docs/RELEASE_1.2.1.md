# DawnMesh 1.2.1 · 两端构建 62

此版本继承 1.2.0 的新图标、可靠文字、独立成员身份与退出换钥、GATT 文字备用、可选语音留言、Wi-Fi Aware 加速与离线密封转交，并修复融合房连接生命周期。

多人入房时，繁忙设备可能超过原来的 4 秒握手期限。近场握手现保留有界的 8 秒窗口；同一目标的并发连接共享同一个结果，超时和退出会取消尚未完成的 HTTP 握手，避免后台遗留连接。公网握手保持原有 5 秒期限并使用相同的取消清理逻辑。加密认证、房间容量、语音和无线能力判定保持原有规则。

加解密队列现在按小批次让网络与计时器继续运行，保持报文顺序和容量上限，避免大量控制报文推迟新成员握手。可选成员路由在内容不变时改为每 30 秒刷新；成员/地址变化、新连接与主动同步仍触发重新广播。房间名单与心跳保留原有同步节奏。

这些可靠传输与离线通信改进借鉴了 Bitchat 的技术思路，采用本项目独立实现；未复制其 GPL 源码，也不代表与 Bitchat 互通。

设备安装与 GATT、Wi-Fi Aware、离线转交、锁屏通话验证见 [五机验收](MANUAL_ACCEPTANCE.md)。自动化不能代替真机射频与功耗验收。iOS 发布产物仍为未签名的 App，安装需自行签名或 TestFlight。

验证：Android 352 项、iOS 371 项完整回归（均含真实本机中继）与静态检查通过；云端连续五轮融合测试及 iOS 原生检查/编译通过。最终签名 APK、AAB 和未签名 iOS App 已生成并校验版本、签名/结构及归档完整性。详见 [验证记录](VALIDATION.md)。
