# DawnMesh 1.0.3（versionCode 41）

- Wi-Fi、蓝牙和公网房统一使用四位数字邀请码，支持随机生成和手动设置；移除旧六位输入、兼容提示及六位隐藏占位符。
- 修复公网房「头像离线但仍能听见语音」：管理连接与语音连接分别处理，头像在线状态以 LiveKit 媒体成员为准。管理连接中断不再把仍在通话的成员标离线；实际媒体成员退出／恢复时更新标记。自身媒体恢复期间保留同伴最后状态，避免把整间房误报掉线。
- 公网入房改由服务端直接验证，不再等待房主处理。房主离线期间，只要房间尚在保留期限内、未满员，成员即可凭正确邀请码加入。
- 新流程用每房随机盐派生独立的入房凭据与密钥封装密钥，随机房间密钥由客户端加密后交给服务器保存、在验证通过后分发。服务端保存凭据摘要，原始邀请码不上传。管理员收听仍需建房时明确授权。
- 配套服务端修复连接替换竞态：旧管理连接迟到的关闭事件不会把已恢复的新连接标为离线。

请同时升级到 DawnMesh Server 0.2.5 并重新创建已有公网房间。公网协议升级为 2；旧房间缺少新入房验证资料，不能自动迁移。四位码属于临时访问控制，服务端数据库泄露后仍可能被离线穷举。

验证覆盖四位码拒绝六位、媒体连接与管理连接分离、恢复在线、跨 Dart/浏览器密钥派生与 AES-GCM 封装、房主离线和数据库重载后入房、错误凭据拒绝、限流与容量控制。没有多手机公网弱网实机验证。按要求只推送分支和标签，不追踪 GitHub Actions。
