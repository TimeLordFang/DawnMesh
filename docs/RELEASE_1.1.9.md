# DawnMesh 1.1.9

- 融合房移除自动 Nearby 配对弹窗，点击房间后直接输入邀请码，确认后自动继续入房；防止重复点击启动重叠的流程。
- 保留 Android / iOS 同一 Wi-Fi、热点互通，以及安卓原生 Wi-Fi Direct、苹果点对点 Wi-Fi 和所选服务器的目录、加密中继。
- 本地连接已打开但邀请码认证无响应时，自动尝试备用本地入口，公网兜底继续独立工作。
- 删除 Nearby 原型、实验集成、实验文档和对应依赖。跨系统、无共同网络的离线自动直连暂缓；不将同网通信当作跨平台 Wi-Fi Direct。

使用相同服务器配置的联网成员可以互补本地链路。完全离线且不在共同 Wi-Fi / 热点中的安卓与 iPhone 暂不支持自动直连。原有邀请码、加密帧和服务器 API 兼容；服务端无需为本版升级。

APK 使用发布签名，可覆盖安装；无需先卸载现有版本。
