# DawnMesh Android 1.1.5

版本：1.1.5+56；配套 iOS 1.0.4，Server/Web 0.3.3 无需升级。

- 安卓蓝牙房主提供完整房名的只读 GATT 服务，与 iOS 使用相同元数据格式；支持中文和 emoji、长名称分段读取、人数更新和蓝牙恢复后重新发布。
- 输入邀请码期间收到的新房名用于入房，避免继续显示旧占位名。旧广播未提供名称时，从已认证房主成员补全房间标题。
- 蓝牙房切换通道后清除旧名称，后续缺名广播不会覆盖同一房间已有的有效名称。
- 保留旧安卓广播发现、邀请码认证、加密语音及聊天协议；iOS 侧滑动画和建房修复由配套 iOS 1.0.4 提供。

验证：安卓 Flutter 297 项、JVM 41 项通过，Lint 0 issues；iOS Flutter 316 项、Swift 190 项检查通过。两端各 1 项真实 Go 中继集成测试因未配置测试服务器按既有配置跳过。静态检查与两端 Release 构建通过，详见 [验证记录](VALIDATION.md)。

建议两端一起升级，安卓房主保持前台，复测附近列表及入房后的名称、双向语音和聊天。本次未重新完成真机射频、混合设备多人及锁屏验收。
