# DawnMesh 1.1.0-beta.2（versionCode 44）

- 公网双线融合改为房主统一开关，服务端保存偏好；成员及后加入者自动跟随。通过公网加密信令交换 Wi-Fi Direct 就绪信息与连接信息，等待建群、重试、房主转让及公网恢复均自动协调。
- 延续单次麦克风采集与接收端互斥播放，直连质量满足门限时优先直连，异常回退公网。释放本次建立的群组，避免残留影响后续连接。
- 三种房间在自动通话和按住对讲期间，前台及锁屏通话面板保持屏幕常亮；退房或结束后解除。
- 房间结束时没有文本消息则直接退出，同时关闭打开的聊天页；有文本则保留查看。网页端同步此行为。
- 热配置已支持服务端开关已有融合能力、调整参数及公告，客户端每 30 秒刷新；关闭后回公网，恢复后按房间偏好自动启用。

配套 **DawnMesh Server 0.3.0-beta.2**，本次房主统一控制需要双方升级一次。后续兼容的服务端逻辑、已有功能开关和参数可只更新服务端；新增原生接口、音频算法或页面组件仍需更新 APK，不提供任意原生代码热更新。

验证：250 项 Flutter 回归、Android 测试/Lint、Go 竞态测试与 vet、网页构建、4 项前端单测及 17 项浏览器回归通过；发布 APK 签名与 16 KB 对齐检查通过。

融合仍为实验功能，公网热备用仍消耗流量。成员无需操作开关，但系统权限或厂商连接确认仍可能需要操作；未进行多手机 P2P/蜂窝并发及真实耳机实测，不能承诺所有设备零丢音切换。详见 [设计与热配置](HYBRID_AND_DYNAMIC_FEATURES.md)。仅推送主分支与标签，不追踪 GitHub Actions。
