# 配色、设置入口与 Android 图标验收

Android / iOS 使用同一套 Logo 配色：靛蓝 `#080F39`、日轮橙 `#FF7446`、暖金 `#FFD587`。浅色页面使用暖白底与深色文字，深色页面使用靛蓝底与暖金操作色；首页、通话、聊天及 Android 锁屏通话面板同步。危险操作仍使用独立的红色。

首页右上只保留设置齿轮，不再用“未读信封”图标表示离线转交。设置页集中提供外观（跟随系统／浅色／深色）、麦克风降噪、离线转交、服务器管理、调试与音频调校、关于和更新。在房间内打开同一页面会额外显示当前房间的安全号码、语音留言、连接和房主控制等适用选项。

## Android 图标调整

之前的自适应前景是 `drawable-nodpi` 下 1024px 位图包在 `LayerDrawable` 里，再通过 18dp 边距缩放。部分厂商桌面在返回桌面动画中单独提取/缩放图层，可能绕过该层的缩放而裁切位图。仅凭现象不能确认所有桌面的内部实现。

现在前景直接使用每种屏幕密度对应的 PNG：108dp 画布、18dp 透明边缘，mdpi 到 xxxhdpi 为 108／162／216／324／432px，保留相同图案、背景与布局。移除重复夜间前景、1024px nodpi 图及 XML 缩放层；legacy、adaptive、round 与 monochrome 入口保留。不更改应用标识或清除用户数据。

## 真机手动检查

1. 在小米、一加、红米安装本次构建的 APK，直接覆盖安装保留设置和聊天数据。
2. 从桌面打开应用，再用 Home 手势最小化，连续 5 次；观察动画开始、中途、结束，图案应始终居中，不出现左上角放大后跳回。
3. 在浅色／深色系统主题、默认／圆形图标样式下重复；支持主题图标的桌面再启用主题图标检查单色轮廓。若桌面仍缓存旧图，先移除快捷方式后重新添加，必要时重启桌面／设备，不要清空应用数据。
4. 首页只应出现一个设置入口，没有离线转交状态小点。进入设置后切换主题，打开离线转交、调试、关于页，再返回，确认路径可达。
5. 建立本地房和公网房，从房间齿轮进入同一设置页；确认房间开关仍有效、返回后通话不中断。用系统最大字体检查滚动、返回与操作。
6. iPhone 17 Pro / XR 检查浅深色、设置返回、附近邀请和通话功能。iOS 无本次 Android 桌面图层问题，图标本体不变。

本地组件截图用于检查颜色和布局，不能替代上述厂商桌面动画与真机无线通话验收。

参考：[Android 自适应图标](https://developer.android.com/develop/ui/compose/system/icon_design_adaptive)。

服务器的添加、编辑和删除统一在“设置 → 服务器”；公网与融合大厅只保留服务器选择和设置入口。通话中的服务器不能编辑或删除，新增其他服务器不会切走当前通话；从设置返回大厅后重新加载配置。公网语音质量也已移入当前房间的设置页。
