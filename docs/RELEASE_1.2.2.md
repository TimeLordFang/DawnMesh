# DawnMesh 1.2.2 · 两端构建 63

保留第一套“曙光声波”图标以及 1.2.0 的可靠文字、独立成员身份与换钥、GATT 文字备用、可选语音留言、Wi-Fi Aware 加速和密封离线转交，并继承 1.2.1 的有界连接清理与加密队列调度。

修复繁忙房间中一次认证报文丢失后持续等待的问题：沿用两秒心跳，对同一握手阶段最多补发五次；传输编号重新生成以穿过中继去重，身份、确认信息及持钥证明保持同一份。已完成的认证响应采用有容量与到期限制的短期密文缓存，重复报文不重新执行口令猜测；换钥和关闭会清理缓存。认证后的入房请求也有有限补发。

保留原有口令猜测限流、成员签名、epoch 和防重放校验。重放已完成的旧握手不能再占住新认证。自动化覆盖逐阶段丢包、补发上限、旧握手重放、换钥缓存失效及多人融合房。

可靠传输与离线能力借鉴 Bitchat 的技术思路，均为本项目独立实现，未复制其 GPL 源码，也不代表与其互通。研究报告不纳入 Git。

Android Release 提供签名 APK 与 Google Play AAB；iOS 提供未签名 App 压缩包，安装需自行签名或 TestFlight。五台设备的射频、配对、功耗与锁屏验收仍按 [手动清单](MANUAL_ACCEPTANCE.md) 执行；自动化不替代真机结果。
