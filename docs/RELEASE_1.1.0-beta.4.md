# DawnMesh 1.1.0-beta.4（versionCode 46）

- 健康直连优先，移除直连 RTT 必须比公网 SFU RTT 低 15% 的不对等比较。正确读取选中 ICE 地址对，按接收流统计增量丢包；静默时保持直连就绪，避免开口后再等待切换。
- 修复关闭移动数据后主动拆除直连的问题。已经通过公网认证、建立的直连在公网重连期间保留，使用自己的加密数据通道保活；单个队友退出不影响其他直连。
- 麦克风由房间会话持有，LiveKit 清理/重建公网连接不会销毁共用采集。PTT、自动通话、静音和耳机恢复继续控制同一个麦克风，公网发布不阻塞直连 PTT。接收端维持一路播放，公网恢复重新选路。
- 公网恢复中明确显示直连是否可用。缓存权限延续最多 30 分钟，恢复后同步服务端权限；超时要求恢复公网。首次入房、新成员认证、完全损坏的直连重新协商、聊天与管理仍需公网。
- Server 0.3.0-beta.3 增加丢包与抖动阈值热配置，客户端联网时约 30 秒获取新值。本次生命周期修复需要双方升级 APK，之后调整已有阈值可只改服务端配置；仍兼容 Server beta.2 的默认值。

多人 Wi-Fi Direct 是单群组组网，融合默认每机至多 4 位直连同伴，最多 5 人可形成完整两两连接。**本版未实现跨群组、扩展距离的多跳 Mesh**；详见 [拓扑调研](WIFI_MESH_TOPOLOGY.md)。

验证结果见 [验证记录](VALIDATION.md)。没有真实多手机、蜂窝/P2P 并发或骑行声学测试，不能把模拟回归当作真机验收。只推送主分支与标签，不追踪 Actions。
