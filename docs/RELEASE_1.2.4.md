# DawnMesh 1.2.4 · 两端构建 65

Android 与 iOS 应用版本统一为 **1.2.4+65**；按候选验证后提升同一提交的流程发布。

- Wi-Fi、蓝牙、融合和公网建房弹窗统一为圆角矩形按钮：取消描边、创建实心，主操作仅显示“创建”。
- 加入、保存、退出、撤回、清空及删除等弹窗共用按钮尺寸和样式；危险操作颜色适配浅深色。邀请码内容在小屏或键盘弹出时可滚动。
- 修正 iOS 服务器弹窗中的平台提示，保留现有连接、认证、通话与取消流程。
- 收拢文档入口：旧版发布说明合并为更新摘要，重复构建和签名流程并入开发与发布指南，清理旧环境结论与一次性验证记录。完整历史仍可从 Git 标签追溯。

Android 提供签名 APK、AAB 及 SHA-256；iOS 提供普通与 Wi-Fi Aware 变体的未签名 App ZIP 及 SHA-256，安装需适当签名。候选 Release 不替换当前正式版；验证通过后才可提升相同提交为正式版本。

当前验证见 [VALIDATION.md](VALIDATION.md)，无线、配对、后台与锁屏继续按 [手动验收](MANUAL_ACCEPTANCE.md) 记录。本轮没有修改传输或加密协议。
