# DawnMesh 1.1.0-beta.7（versionCode 49）

融合房统一展示公网、局域网与 Wi-Fi Direct 发现结果，并修正独自建房时容易误解的网络状态提示。

- 按房间 ID 合并来源，保留同房间的多个本地连接入口；同名的不同房间分别展示，成员人数不重复累加。
- Wi-Fi Direct 增加公开房间标识广播。未提供房间标识的旧版设备单列展示，仍可尝试手动选择直连。
- 入房优先尝试已有局域网连接，失败再尝试公网及附近直连；已入房的公网成员继续自动协商本地连接。
- 单人建房时显示直连入口就绪、等待队友，不再把创建群组写成已连接 Wi-Fi 并协商语音。
- 服务端未提供融合房接口时明确提示更新服务端，并区分访问凭证错误、超时及公网中继连接失败。创建者独自建房也会立即尝试同步公网。

需要更新 **APK**。服务端最低版本仍为 **0.3.0-beta.4**；已有此版本或兼容更新版本的服务器无需再次升级。服务端热配置无法修改旧 APK 的发现接口和提示逻辑。

Wi-Fi 房和融合房继续保留 **6 人**上限，这是当前应用协议限制，不是 Wi-Fi 信道固定容量。本版未进行跨品牌手机的无线发现实测。详见 [融合房说明](FUSION_ROOMS.md) 和 [验证记录](VALIDATION.md)。

本次只推送 GitHub 主分支和版本标签，不追踪 Actions 执行情况，也不自动部署服务器。
