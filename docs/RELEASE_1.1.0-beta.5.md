# DawnMesh 1.1.0-beta.5（versionCode 47）

修复公网融合房重连期间可能绕过“按住对讲”的底层开麦入口。用户反馈房主重连后能听到未按键成员的声音；代码排查确认 SDK 可直接解除音轨静音，而旧版没有在音轨层校验本机对讲状态。尚未在对应手机上复现完整触发过程。

- 音轨开启、解除静音及重新启动均受本机 PTT、自动通话、静音、权限与退房状态约束。
- 松手立即关闭实际音轨，不再等待正在执行的重连或采集任务；即使 SDK 静音标记已经为真，也会确保实际轨道关闭。
- 重建采集时先检查最新发言状态，再挂载到发送器。公网发送器已失效时保留直连采集能力。
- 新增 SDK 直接开麦、重建中松手、房主快照与权限恢复，以及房主直连重新协商的组合回归，确认再次主动按下后仍能正常发言。

本次必须更新 APK，建议所有参与者升级。无需更新服务端，继续兼容 Server 0.3.0-beta.3；服务端热配置只能调整已实现的能力和参数，不能修复旧 APK 的本地音轨逻辑。

验证结果见 [验证记录](VALIDATION.md)，代码依据与真机复测步骤见 [排查说明](PTT_RECONNECT_INVESTIGATION.md)。沿用 beta.4 的离线直连续通话和单群组拓扑边界。本次只推送主分支与新标签，不追踪 GitHub Actions。
