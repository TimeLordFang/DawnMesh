# DawnMesh 1.1.2（versionCode 53）

修复重连期间的安全状态和通话生命周期问题，保持现有线协议兼容。

- 同一房间密钥重新握手时保留防重放窗口与发送计数，重连后继续拒绝已接收的旧密文；成功握手不再消耗累计失败预算。
- 两个 Android 前台服务入口等待真实启动结果；失败、取消、超时和异常销毁时清理采集，旧回调不能影响新会话。
- 前台服务统一管理音频焦点，失焦停止采集并释放 PTT；恢复遵循语音模式和静音状态，服务失败后不得自动开麦。
- 对讲按钮支持读屏开始/停止，退出和进入后台时释放；通知补充中英文资源。
- 清理未使用的旧加密入口、UI、FFI 和原生协议代码，同步构建与测试入口。

已通过 295 项 Dart 回归（包含真实 Go 融合中继）、静态分析、37 项 JVM 单测、Debug Lint、Debug APK 构建和 64 位 ELF 对齐检查，以及原生 ASan/UBSan 回归。版本递增不改依赖或协议。
配套 iOS 1.0.1、Server/Web 0.3.2。来电、蓝牙、后台音频和 TalkBack 仍需真机验收；正式签名包由标签发布流程构建。
