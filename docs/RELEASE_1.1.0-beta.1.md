# DawnMesh 1.1.0-beta.1（versionCode 43）

- 蓝牙耳机因距离断开后，连接状态稳定时恢复通信路由并重建麦克风采集。Wi-Fi/蓝牙近场房和公网房分别处理各自的录音管线；保留静音、PTT 和房主发言策略。
- 公网房以持久化安装身份及独立私有凭证恢复原成员，避免重复加入生成两个成员，保留房主身份和禁言状态。新安装使用 UUID v4，已有安装不更换 ID。
- 公网房新增手动开启的双线融合（实验）：尝试 Wi-Fi Direct/局域网点对点音频，质量连续合格后优先直连，变差时回公网；只采集一次，接收端只播放一路。
- 新增服务端能力清单与每 30 秒动态刷新，可远程开关已有融合能力、调整质量门限、显示公告，无需重新安装 APK。新增原生功能仍需更新客户端。

配套 **DawnMesh Server 0.3.0-beta.1**，协议仍为 2；连接旧服务端时不显示融合功能。旧版未绑定设备凭证的历史成员，需要先退出/移除旧会话或重建房间后绑定身份。

融合需双方分别开启，建议房主先开。公网保持热备用，仍消耗流量；公网媒体重连会关闭融合，恢复后可重新开启。实际效果依赖手机 P2P 与公网并发能力。本次没有真实耳机距离断连或多手机道路测试，请按 Beta 版本验证，不能保证所有耳机都能恢复或切换完全无感。

验证：244 项 Flutter 回归、Android 测试/Lint、服务端竞态回归及网页回归通过；发布包签名与 16 KB 对齐检查通过。
