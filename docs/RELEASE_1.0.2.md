# DawnMesh 1.0.2（versionCode 40）

- Wi-Fi、蓝牙、公网房创建时共用同一个验证码输入组件，随机生成按钮统一放在输入框右端，保留手动输入和旧版六位码兼容。网页创建表单同步调整。
- 降噪菜单改为紧凑的三项列表；入口移到房间顶部工具区，发言方式行只保留「按住对讲 / 自动通话」。降噪算法和档位不变。
- 公网房以服务端保留的成员名单作为头像来源，再叠加媒体连接状态。掉线后保留头像和顺序，在头像上显示「离线」标记；恢复后移除标记，主动离开后移出列表。离线成员不能被选择为下一任房主。
- 公网房主可在顶部铃铛入口开启或关闭全房间的掉线／退出语音提示，默认关闭。设置随房间保存在服务端，重启和移交房主后继续有效；服务端在锁内核验当前房主权限。
- 掉线持续两秒才播报，短暂恢复会取消待播提示；主动退出由服务端明确事件触发，不把成员回收、首次进房或重连同步当成新退出。相同退出事件去重，关闭开关及退出房间时取消待播提示。
- Android 使用系统已安装的离线中文语音，支持时读出成员昵称；没有中文时尝试离线英文，没有可用离线语音时播放短提示音。声音使用当前通话路由，不抢占音频焦点。网页语音依赖浏览器本地中文语音与播放权限，头像状态始终可见。

公网房间开关需配套 DawnMesh Server 0.2.4 或更新版本；旧服务端仍可使用离线头像，开关入口提示升级。旧版客户端可以继续通话，但不会播放新增提示。

验证覆盖初始名单静默、短暂掉线取消、持续掉线单次提示、退出事件去重、关闭/重连/释放时清理，成员顺序与离线标记，小屏与大字号布局，以及服务端房主权限、设置持久化和明确离房事件。无多手机/耳机实机路由和系统语音引擎听感验证。

平台依据：[Android TextToSpeech](https://developer.android.com/reference/android/speech/tts/TextToSpeech)、[离线 Voice 属性](https://developer.android.com/reference/android/speech/tts/Voice#isNetworkConnectionRequired())。
