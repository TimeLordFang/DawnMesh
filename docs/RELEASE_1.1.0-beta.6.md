# DawnMesh 1.1.0-beta.6（versionCode 48）

公网房恢复为纯公网模式，双线通信改为首页独立的「融合房」。

- 无需公网即可创建融合房、通过附近任一已连接成员验证四位码并加入。
- 任一联网成员可同步房主签名的成员名单，并连接远程队友；房主可以不联网。
- 多个网关同时工作，密文包去重避免重复语音；其中一位网关退出后，其他已有上行可继续转发。
- 已入房成员通过加密通道自动交换 Wi-Fi Direct 就绪信息，本地连接与公网备用并存。
- 融合房默认按住对讲，保留降噪、屏幕常亮和无文本消息时直接退出的行为；重连时不会把未按键成员改为自动发言。

需要同步升级 **APK 与 Server 0.3.0-beta.4**。本版融合房上限 6 人；附近离线加入需要实际可用的 Wi-Fi、热点或 Wi-Fi Direct 连接。它支持应用层转发，不是跨 Android Wi-Fi Direct 群组的无线 Mesh，也没有实现房主永久离开后的离线选举。

详见 [融合房设计与边界](FUSION_ROOMS.md) 和 [验证记录](VALIDATION.md)。本次只推送主分支与标签，不追踪 GitHub Actions，也不代表已部署到用户的服务器。
