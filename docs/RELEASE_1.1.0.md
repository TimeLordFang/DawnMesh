# DawnMesh 1.1.0（versionCode 51）

正式版整合本轮开发的独立融合房、离线通信、设备身份、降噪与重连修复，并将 Wi-Fi 房和融合房扩大到 16 人（含房主）。

- 同步调整成员号、LAN 连接数、入房验证、发现界面、交接名单及融合签名校验；蓝牙房保持 6 人。
- 长名单、交接计划与融合签名状态使用有界加密分片，物理帧仍为 512 字节；完整组装后才生效，拒绝截断、冲突、过期和非法控制消息。
- 融合房自动互连优先形成成员环路，保留已有引导连接，减少全互连重复发送；提高配套中继容量、合理限流与去重缓存。
- 保留清晰/平衡/省流、降噪、四位邀请码、公网/本地房间去重发现、已入房身份恢复、30 分钟恢复期和重连 PTT 保护。
- 审阅并统一容量与 UTF-8 截断处理，合并重复房主命令校验；中文昵称不会因字节边界截断损坏，半份名单不会更新成员列表。

所有成员需更新 **Android 1.1.0**，融合房配套 **Server 0.3.0**。客户端容量/分片/UI 需要 APK 更新，服务端热配置不能向旧客户端注入协议。

原 6 人限制来自应用实现；实际 Wi-Fi Direct 群组容量另受手机驱动和系统配置影响。16 人真实套接字测试不等于已经完成 16 台不同品牌手机的无线及同时讲话实测。成员仍需可用 IP 链路，房主作为唯一无线群组所有者离开后的群组自动迁移未实现。

验证记录见 [VALIDATION](VALIDATION.md)，容量与无线边界见 [融合房说明](FUSION_ROOMS.md)。发布仅推送 GitHub 主分支和正式标签，不追踪 Actions、不自动部署服务器。

## 正式版完整功能与升级边界

本节汇总预发布阶段最终保留的能力；早期公网房内的 WebRTC 双线融合已由独立融合房取代。

- **离线创建与多网关转发**：四位码经 SPAKE2 验证；可经附近已入房成员把握手转发到逻辑房主。任一联网成员同步房主签名名单，多网关转发密文并去重，单个网关退出不影响其他已有路径。
- **统一发现**：按房间 ID 合并服务器、局域网和 Wi-Fi Direct 入口，保留备用地址，不重复累加人数；同名不同 ID 分列。独自建房显示入口就绪、等待队友，旧服务端、凭据错误与中继失败分别提示。
- **已入房身份恢复**：成员交换加密的本地地址，保持可达成员间通信；全部队友失联才进入 30 分钟恢复期，保留成员号、名单和密钥。服务端允许持有原房间能力的成员在旧签名快照下恢复仍有效的中继记录。
- **公网安装身份**：持久安装 ID 配合独立设备私有凭证恢复原成员、房主身份和禁麦状态；恢复轮换令牌并撤销旧管理连接。未绑定私有凭证的旧会话不能仅凭 UUID 接管，需要退出旧会话、移除旧成员或重新建房。
- **耳机恢复与 PTT**：蓝牙耳机路由恢复后重建对应采集管线；开麦、解除静音和采集重建均受最新 PTT、静音、权限及退房状态约束，松手立即关闭实际音轨。SDK 的直接开麦请求不能自行授权发言。
- **房内交互**：设置集中在可滚动面板；活动通话按状态保持屏幕常亮，退房后解除。结束时无文本则退出，有文本可留在房间查看。融合房音质切换不重启录音、不改变 PTT 状态。
- **动态能力边界**：服务端可发布已有能力参数和公告；正式版普通公网房保持纯 LiveKit，旧融合开关不能重新启用。新增协议、原生接口、音频算法或界面仍需安装新版客户端。

新成员入房仍需最终可达逻辑房主；服务端重启后需要新鲜签名快照重建融合记录。没有实现无线群组所有者自动迁移或离线分区选举。公网备用路径仍使用流量。

自动化覆盖错误码拒绝、身份恢复、签名篡改拒绝、环路去重、多网关、远程入房与解散、PTT 重连保护和 16 人容量；实际无线与声学表现仍按 [验证与验收](VALIDATION.md) 检查。
