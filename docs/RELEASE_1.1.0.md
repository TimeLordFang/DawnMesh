# DawnMesh 1.1.0（versionCode 51）

正式版整合 1.1.0 Beta 阶段的独立融合房、离线通信、设备身份、降噪与重连修复，并将 Wi-Fi 房和融合房扩大到 16 人（含房主）。

- 同步调整成员号、LAN 连接数、入房验证、发现界面、交接名单及融合签名校验；蓝牙房保持 6 人。
- 长名单、交接计划与融合签名状态使用有界加密分片，物理帧仍为 512 字节；完整组装后才生效，拒绝截断、冲突、过期和非法控制消息。
- 融合房自动互连优先形成成员环路，保留已有引导连接，减少全互连重复发送；提高配套中继容量、合理限流与去重缓存。
- 保留清晰/平衡/省流、降噪、四位邀请码、公网/本地房间去重发现、已入房身份恢复、30 分钟恢复期和重连 PTT 保护。
- 审阅并统一容量与 UTF-8 截断处理，合并重复房主命令校验；中文昵称不会因字节边界截断损坏，半份名单不会更新成员列表。

所有成员需更新 **Android 1.1.0**，融合房配套 **Server 0.3.0**。客户端容量/分片/UI 需要 APK 更新，服务端热配置不能向旧客户端注入协议。

原 6 人限制来自应用实现；实际 Wi-Fi Direct 群组容量另受手机驱动和系统配置影响。16 人真实套接字测试不等于已经完成 16 台不同品牌手机的无线及同时讲话实测。成员仍需可用 IP 链路，房主作为唯一无线群组所有者离开后的群组自动迁移未实现。

验证记录见 [VALIDATION](VALIDATION.md)，容量与无线边界见 [融合房说明](FUSION_ROOMS.md)。发布仅推送 GitHub 主分支和正式标签，不追踪 Actions、不自动部署服务器。
