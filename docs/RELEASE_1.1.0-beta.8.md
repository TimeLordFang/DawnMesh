# DawnMesh 1.1.0-beta.8（versionCode 50）

融合房新增与公网房一致的清晰、平衡、省流音质，并减少已入房成员通话对房主在线状态的依赖。

- 房间设置中切换音质，直接调整本机 Opus 码率，不重启录音或改变按住对讲状态。移动网络默认省流，Wi-Fi 默认清晰；手动选择后保留所选档位。
- 已入房成员通过加密通道交换本地连接地址，自动建立成员之间可达的连接，支持应用层密文转发和去重。
- 取消房主 12 秒无数据后的重新验码。其他已验证成员仍可达时继续通话；全部队友失联才进入 30 分钟恢复期，沿用成员号、名单和密钥，只恢复传输链路。
- 收到已知成员的合法加密数据后恢复通话，保持按住对讲松开，防止重连误开麦。
- 配套服务端允许已入房成员在房主快照过期后凭原房间能力恢复公网中继；有效成员数据续期记录，不修改房主签名。

需要更新 **APK 和 Server 0.3.0-beta.5**。服务端热配置无法向旧 APK 增加互连逻辑或音质界面。

成员之间仍需可用的本地或公网链路。若房主是唯一 Wi-Fi Direct 群组所有者，其离开导致整个群组消失时，本版不会自动迁移群组所有者；这不是跨群组无线 Mesh。新成员入房仍需最终可达房主，明确解散仍结束房间。6 人上限不变。双线路同时传输仍消耗公网流量。

验证：64 项 Flutter 回归通过，包括真实 Go 中继集成、成员直连后房主消失、语音去重、PTT 保护、30 分钟恢复和窄屏音质菜单；相关静态分析通过。未进行多台 Android 手机的射频或道路实测，本轮未在本机重新构建签名 APK。

发布仅推送 GitHub 主分支及标签，不追踪 Actions，也不代表服务器已自动部署。
