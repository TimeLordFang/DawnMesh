# DawnMesh 1.1.0-beta.3（versionCode 45）

- 修复融合直连未接入 WebRTC Wi-Fi Direct 网卡监听的问题，在权限检查后动态补充直连网卡并保留公网网卡，持续收集候选地址，并通过公网加密信令补发建群后才出现的私网地址。接收端处理先到地址与晚到 SDP，按设备和协商会话隔离。
- 移除底层“已返回失败后又偷偷建群”的重试，由融合协调器统一重试。残留群组的 SSID 匹配当前房间时自动接管并广播，其他群组不受影响。
- 拆分“已连接”和“实际使用直连语音”状态；无语音时也能确认连接是否建立。权限、Wi-Fi、定位、等待房主与建链重试有明确提示。静默期间预热连接质量判断，实际播放仍要求收到语音包，接收端只播放一路。
- 三种房间右上角统一为设置面板。公网的降噪、融合、离线提示及改名，近场的降噪、日志及诊断不再挤占状态区域；大字体面板可滚动，房间结束时关闭面板。

继续兼容 Server 0.3.0-beta.2，无须为本次客户端修复升级服务端。直连两端都应更新本版，房主开启一次后成员自动跟随。服务端主分支另已修复 protobuf 依赖分类导致的 CI 校验失败。

258 项 Flutter 回归、Android 单元测试/Lint、发布 APK 签名及 16 KB 对齐检查通过。自动化覆盖晚到地址补发、先于 SDP 的地址暂存、会话隔离、地址过滤和上限、权限恢复、建群重试、残留群组恢复、空闲连接计数及菜单布局。未完成两台真实手机的 Wi-Fi/蜂窝并发验证，不能将代码修复等同于所有机型已实测连接成功。

详见 [融合设计与排查](HYBRID_AND_DYNAMIC_FEATURES.md)。只推送主分支及标签，不追踪 GitHub Actions。
