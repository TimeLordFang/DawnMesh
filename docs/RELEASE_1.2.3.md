# DawnMesh 1.2.3 · 两端构建 64

Android 与 iOS 统一版本为 **1.2.3+64**。

- 统一晨光配色：首页从靛蓝、桃橙与暖金自然过渡到米白，文字在左、太阳偏右并避开设置按钮。浅深色使用相同的动态波纹，小字统一为“越过地平线，让声音相遇。”。
- 统一设置入口：外观、离线转交、服务器管理、调试与音频调校集中到设置页；房内仍提供适用于当前房间的控制。首页不再以未读消息样式显示功能配置。
- 调整 Android 自适应图标的密度资源和透明边距，改善部分桌面返回动画中的裁切风险；iOS 保留相同图形。更新锁定的音频、网络与构建依赖。
- iOS 默认签名配置移除 Wi-Fi Aware 能力要求，兼容 Personal Team 的基础功能构建；保留需要相应账号、系统和硬件支持的独立 Aware 配置，详见 [iOS 签名说明](https://github.com/TimeLordFang/DawnMeshIOS/blob/main/docs/XCODE_SIGNING.md)。
- 加强发布验证：同步中英文文案断言；独立验证有界入房重试丢包恢复与 16 人名单、密钥收敛，保留签名、语音去重和人数上限检查；候选通过后才提升同一提交为正式版本。

延续此前对 Bitchat 可靠传输与离线通信思路的借鉴，由本项目独立实现；技术研究报告不纳入 Git，也不表示两个应用能够互通。

Android 提供签名 APK、Google Play AAB 及各自的 SHA-256 校验文件。iOS 提供普通版和可选 Wi-Fi Aware 版未签名 App 压缩包及校验文件，安装需要相应签名；普通版不要求 Wi-Fi Aware 签名能力。

射频互通、设备配对、功耗与锁屏行为仍按 [手动验收清单](MANUAL_ACCEPTANCE.md) 检查。自动化构建和协议测试不等同于上述真机项目已通过。版本验证记录见 [VALIDATION.md](VALIDATION.md)。
