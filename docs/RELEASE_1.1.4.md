# DawnMesh Android 1.1.4

版本：1.1.4+55；配套 iOS 1.0.3，Server/Web 0.3.3 无需升级。

- 扫描到 DawnMesh 服务且没有旧版厂商广播时，通过 GATT 读取房名、人数和动态 L2CAP PSM，可发现并加入 iOS 1.0.3 房主。
- GATT 读取限制最多四条并发、64 台缓存、五秒超时和三秒重试间隔；停止扫描时取消未完成连接。
- 保留旧安卓广播发现和原有 PAKE/加密帧，安卓房主的旧客户端兼容性不变。新增元数据不参与身份认证。
- 备用 PNG 启动图标使用与 iOS 相同的 DawnMesh 设计，保留自适应/单色图标；旧备用图标按平台要求保留透明圆角轮廓。

苹果点对点 Wi-Fi 仅连接苹果设备；安卓与 iOS 的 Wi-Fi 房仍通过同网/热点互通，也可使用蓝牙或公网房。

iOS 蓝牙房主首次发现和入房需保持前台。混合设备蓝牙语音、多人数容量及锁屏恢复须按 iOS 仓库新增清单实测；协议上限六人不等同于硬件稳定容量。
