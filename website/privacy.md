## 1. 适用范围与联系方式 {#scope}

本隐私政策适用于 **曙光之声（DawnMesh）Android 应用**，包名为 `dev.dawnmesh.intercom`，以及本应用主页。开发者为 **{{ site.developer }}**。隐私问题、数据处理咨询或删除请求，请发送邮件至 **[{{ site.contact_email }}](mailto:{{ site.contact_email }})**。

DawnMesh 是语音对讲和小组通信应用，支持附近设备通信，以及通过用户自行选择的服务器进行远程通信。Android 客户端不要求你注册开发者运营的账号，不内置公共服务器、广告、用户行为分析或遥测服务，不出售个人数据。

“不内置遥测”不代表应用不处理敏感数据。语音、文字、图片及连接信息仍会根据你使用的功能，在设备、房间成员和所选服务之间处理。

## 2. 处理的数据和用途 {#data}

### 语音与麦克风

获得麦克风授权后，应用在你发言时采集音频，用于按住对讲、自动发言和语音传输，可在设备上进行降噪处理。启用自动发言时，应用需要持续处理麦克风输入以判断是否发言。处于活动通话时，语音功能可通过 Android 前台服务在后台或锁屏下继续工作，系统会显示相应通知或麦克风指示；静音、停止发言或退出房间可停止相应的语音发送。

实时语音按房型发送给附近参与者，或通过你选择的服务器及其 LiveKit 媒体服务传输给房间成员。普通实时音频用于即时播放，不由客户端作为永久录音保存。语音留言为可选功能，默认关闭；启用后，可暂存在会话内存中的按键语音片段每段最长为 15 秒，供房间内补送或播放。

### 文字、图片及房间信息

应用处理你主动输入的昵称、房间名称、文字消息以及选择发送的图片，用于显示身份、建房、入房和小组聊天。这些内容会传输给相应房间参与者；远程功能还通过你选择的服务传输。普通房间聊天和图片在会话内存中处理。你主动保存的图片会另存到系统相册，由你自行管理。图片内容本身及文件可能包含可识别个人的信息，发送前请自行检查。

### 设备发现和连接信息

为发现、连接和维护附近设备，应用会处理可用网络状态、局域网 IP 地址、Wi-Fi／蓝牙链路标识、设备或成员标识、房间发现广播和连接状态。附近设备可能看到房间名称、人数、广播标识等发现信息。应用不使用位置权限获取 GPS 坐标或建立地理位置轨迹。

远程连接还会向你配置的服务传输连接所需的安装标识、身份验证信息、房间或成员标识、会话令牌及公钥信息；服务与网络提供方可见源 IP、连接时间和流量等网络元数据。具体服务器的日志、部署地区和保留方式由其运营者决定。

### 本机设置、身份和凭证

应用会在本机保存昵称、音频及外观偏好、调试开关等设置；在设备安全存储中保存身份密钥、随机生成的安装标识和凭证、服务器配置及访问凭证，用于验证身份、加密通信和恢复连接。这些安装标识由应用生成，并非 Android 广告 ID、IMEI 或 SIM 序列号。应用不读取系统电话簿；下述离线转交联系人由你在应用内主动记住。

### 可选离线密封转交

离线转交默认关闭。你主动启用后，应用会在本机持久保存加密的转交消息、你记住的联系人名称及其公钥身份，以及发送者、收件人、消息摘要、大小、创建／到期时间、跳数等必要元数据。消息正文加密给收件人；参与转交的其他设备会保存和传递密文，可见路由身份、大小和到期时间。发送者本机还会保存用于显示自己已发留言的内容，存储整体受本机加密保护。

此功能用于在设备相遇时转交消息，不保证投递成功，不代表匿名通信。联系人信息不受消息 24 小时有效期限制，直到你主动删除。

### 诊断、更新和主动联系

应用在本机处理运行错误和诊断信息，可能包含应用版本、设备／系统信息、音频或网络状态、成员昵称、地址及连接上下文。诊断与调试日志不自动上传给开发者。你主动复制、导出或发送报告时，内容会由你选择的应用或收件人接收，发送前请检查并移除敏感信息。

你点击“检查更新”时，应用会请求 GitHub API 获取版本信息，并发送常规网络连接信息及 DawnMesh 版本的 User-Agent；打开下载链接时由浏览器访问 GitHub。通过邮件或 GitHub 联系开发者时，我们会收到你提供的地址、内容和附件，仅用于回复咨询、排查问题或处理请求。

## 3. 设备权限 {#permissions}

| 权限或设备能力 | 用途 |
| --- | --- |
| 麦克风与音频设置 | 采集对讲音频、降噪、选择扬声器或耳机等音频路由。 |
| 附近 Wi-Fi、蓝牙扫描／连接／广播 | 发现并连接附近设备；能力取决于系统及硬件。 |
| 较旧 Android 版本的位置权限 | 系统要求此权限才能扫描 Wi-Fi 或蓝牙；不用于 GPS 定位或位置追踪。 |
| 网络和 Wi-Fi 状态、网络访问 | 附近 TCP／UDP 通信、网络切换、连接自选服务器及主动检查更新。 |
| 通知、前台服务与活动通话唤醒锁 | 显示活动通话状态，并支持后台、锁屏通话和连接维护。 |
| 系统图片选择与相册保存 | 读取你选择发送的图片，或保存你主动选择的聊天图片；Android 10 及以下保存图片可能需要存储权限。 |

你可以在 Android 系统设置中管理权限。拒绝相关权限可能导致对应功能不可用；已发出的内容不会因撤销权限而自动删除。

## 4. 数据的分享对象 {#sharing}

数据仅按所选功能向以下类型的对象传输或开放：

- **房间成员及附近设备**：接收你发送的语音、文字、图片、昵称等信息，或看到发现广播和连接元数据。合法参与者可以另行录音、截屏、保存或转发内容。
- **融合网关与离线转交设备**：按协议中继加密帧或保存转交密文，并处理路由、大小、时序、到期时间等元数据。
- **你选择的服务器运营者及其基础设施提供方**：包括 DawnMesh 控制服务、LiveKit 媒体服务及该运营者使用的托管、代理和网络服务。其处理范围和日志由部署方式决定，请向运营者了解其隐私政策。使用 LiveKit／WebRTC 客户端库并不意味着所有流量都会发给库作者运营的云服务。
- **获得明确授权的房间管理员**：管理员收听默认关闭。仅在建房时明确允许管理员收听的房间，相关媒体密钥才会托管给服务器，获得权限的管理员能够收听；此类房间不能视为对管理员保密。
- **GitHub 及你主动选择的外部应用或联系人**：用于版本检查、下载、访问项目、分享诊断和处理咨询。外部服务按其各自政策处理收到的数据。

开发者不会仅因你使用附近通信，就自动收到你的语音、聊天或离线转交内容。你配置的服务器、其他用户或外部服务不由本政策代为承诺其保留和删除行为。开发者如依法必须披露其实际持有的咨询等数据，仅在适用法律要求范围内处理。

## 5. 数据保留与删除 {#retention}

- **普通会话内容**：普通聊天、图片及可选语音留言保留在会话内存中，退出房间后由客户端清除。其他成员、网关或你使用的服务器可能仍保有自己的副本或记录。
- **离线转交消息**：消息有效期最长 24 小时，到期后会在应用下一次启动或参与交换时清理；应用未运行时无法保证在到期瞬间删除磁盘记录。关闭转交只停止交换，不删除已存数据。进入“离线转交”，选择“清空并关闭”可删除本机队列和联系人。撤回向合作节点传播签名撤回通知，无法抹去已读内容或不合作节点的副本。
- **联系人、偏好与密钥**：联系人保留至你忘记联系人或清空转交数据；设置、身份和服务器凭证保留至相应配置被删除或应用数据被清除。你可在 Android 系统中清除应用存储或卸载应用以移除本机应用私有数据。Android 备份与设备迁移规则排除了应用身份、凭证和房间密钥。
- **已保存或导出的内容**：相册图片、已复制或导出的诊断信息须在相册、文件、剪贴板或接收应用中自行删除；卸载 DawnMesh 不会删除外部副本。
- **服务器数据**：请联系你选择的服务器运营者，申请访问、更正或删除其保存的信息；开发者无法直接删除独立运营实例上的数据。
- **你向开发者发送的咨询**：保留至解决咨询或请求所需的时间；你可通过上面的邮箱提出删除申请。依法必须继续保留的部分，会仅在必要范围和期限内保留。公开提交到 GitHub 的内容还需遵循 GitHub 的管理和删除机制。

本客户端没有开发者运营的注册账号，因此不存在相应的客户端账号注销流程。删除本机数据会改变或移除本机身份，但不能自动撤销其他设备已取得的数据。

## 6. 安全措施与用户选择 {#security}

应用使用设备安全存储保护持久身份与凭证；近场协议采用身份验证和加密帧，公网房使用媒体端到端加密和聊天加密，融合中继转发密文。远程服务应使用 HTTPS／WSS。离线转交的本机存储加密，消息正文另外密封给收件人。

加密不隐藏所有元数据，也不能防止合法收件人保存内容。四位邀请码只适合临时可信小组，不能等同高强度密码；允许管理员收听的房间有上文所述例外。任何系统都无法保证绝对安全，项目未宣称已完成独立密码学审计。

你可以选择附近模式、管理服务器配置、静音或结束通话、关闭可选留言与转交、清空转交数据，以及在系统中撤回权限。需要访问、更正或删除开发者实际持有的咨询数据时，请联系隐私邮箱；我们可能要求必要信息以验证请求，避免向他人披露数据。请勿在公开 Issue 中发送私钥、邀请码、访问令牌或个人敏感信息。

本应用不专门面向儿童。若监护人认为儿童向开发者提交了个人信息，可通过隐私邮箱联系我们处理。

## 7. 网站、外部服务与政策更新 {#website}

本主页及隐私政策通过 **GitHub Pages** 提供，不设置分析、广告或追踪 Cookie，不嵌入第三方统计、字体或脚本。为提供网页，GitHub 及其基础设施仍会处理 IP 地址、请求时间、浏览器信息和请求日志等常规访问数据，详见 [GitHub 隐私声明](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement)。你使用的独立服务器或第三方服务可能位于不同国家或地区；连接前请向运营者了解其数据处理地区及政策。

我们会在此页面发布隐私政策更新并修改顶部日期。若数据处理方式发生需要另行告知或同意的重大变化，会在相应功能中提供所需说明或征求同意。
